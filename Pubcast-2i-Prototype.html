File controls: rename the document in the title field, use Save to update the current file, or Save As to choose a new filename and location. 2i documents use the .2i format so the collaborative state can be reopened by a future 2i document loader. Voice input uses the browser microphone and speech recognition; the captured text is ready to be handed to the PubPartner provider when that connection is wired in. Flow: new text appears on the "now reading" line at the bottom and lights up left-to-right as it's spoken. Once fully read, it moves up into the buffer zone (pencil, lined paper) — visible, still yours to edit. When the buffer zone is full, its oldest line crosses the threshold into the finalized manuscript. Finalized text is displayed on ruled paper with line numbers that restart in each chapter. Click a line number to select it; use Menu → Unlock selected / line to edit it deliberately. Ctrl/Cmd+A cycles paragraph → page → document in the active editor. Click any line (reading or buffered) to pause and edit it directly — everything after it regenerates. Finalized text is locked by default. Use Menu → Unlock finalized paragraph to deliberately unlock one paragraph; unlocking never happens by clicking the manuscript.
